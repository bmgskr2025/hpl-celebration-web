# 브랜드 자료 (Brand Assets)

이 폴더는 HPL 셀러브레이션 사이트 제작에 사용하는 원본 브랜드 자료 보관용입니다.

## 폴더 구성

| 위치 | 내용 |
|------|------|
| `brand/` | 브랜드 북 (PDF 등) |
| `brand/logos/` | 로고 파일 (PNG, SVG, AI 등 원본) |

## 파일 올리는 방법 (GitHub 웹에서)

1. GitHub에서 이 저장소를 엽니다
2. 왼쪽 위 브랜치 선택에서 `claude/herbalife-premier-league-site-g34ugm` 브랜치를 선택합니다
3. `brand` 폴더(로고는 `brand/logos` 폴더)로 들어갑니다
4. 오른쪽 위 **Add file → Upload files** 를 누릅니다
5. 파일을 끌어다 놓고 아래 **Commit changes** 버튼을 누릅니다

- 여러 파일을 한 번에 올릴 수 있습니다 (파일 1개당 최대 25MB)
- 올린 뒤 채팅에서 "브랜드 북 올렸어요"라고 알려주시면 반영합니다
